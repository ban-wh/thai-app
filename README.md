# Thai Practice

A small web app for English speakers learning Thai: vocabulary by topic, fill-in-the-blank sentences, and the Thai alphabet (consonants, vowels in short/long pairs with example words, final sounds, and a blending drill).

**Open the app:** https://ban-wh.github.io/thai-app/

- Works in any modern mobile or desktop browser (Chrome or Safari recommended; letter sounds use the device's Thai text-to-speech voice).
- Progress is stored only in your own browser. Use **Settings → Backup → Save backup file** before changing phones or clearing browser data, and **Load backup file** to restore.
- Romanization: Paiboon+ and an easy "karaoke" spelling.

Feedback welcome — send a screenshot of anything that looks wrong.
